# DR Agenda Do Trabalho Digno Example

Use the committed artifacts and generated index first.

- `artifacts/registry/`: canonical source registry
- `artifacts/entities/`: canonical entity anchors
- `artifacts/resolutions/`: reusable interpretations and crosswalks
- `archive-evals/scenarios/`: committed eval fixtures

Rebuild with `python3 scripts/rebuild_index.py`.
Verify with `python3 scripts/archive_verifier.py ...`.
