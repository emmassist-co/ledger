# PDF Parser

Prefer Markdown-preserving extraction. Preserve page boundaries, speaker turns, votes, interruptions, and procedural notes.

## Rules

- Use Markdown-first extraction with plain-text fallback.
- Keep procedural content; it is politically relevant.
- Preserve enough structure for later section detection and human inspection.
