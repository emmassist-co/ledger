# Complexity Slider Renderer

All levels must derive from the same underlying notes.

## Rules

- Use section notes, claims, and fetched sources only.
- Do not introduce new facts.
- If something is a claim, keep it labeled as a claim.
- Match tone and density to the requested level without changing substance.
